# AUTO CREW

Автомобильный бизнес-симулятор в Telegram Mini App: от ржавого гаража до собственной автомобильной империи.

- Документ аудита и проектирования: [`docs/01-audit-and-design.md`](docs/01-audit-and-design.md)
- Модель баланса: `python3 tools/balance_sim.py` (`--casual` — игрок, который заходит 4 дня из 7)

## Устройство

| Папка | Что там |
|---|---|
| `src/shared` | Каталоги контента (машины, запчасти, работы, поставщики, ступени), время, детерминированный ГСЧ |
| `src/worker` | Cloudflare Worker: игровые правила (`game.ts`), запись в D1 (`db.ts`), API, бот |
| `src/client` | Mini App: интерфейс и пиксель-арт сцена |
| `migrations` | SQL-миграции D1 |
| `releases.json` | Манифест релизов: первая запись — текущая версия, из неё строятся уведомление в игре и пост в канал |

Сервер — единственный источник истины. Клиент отправляет команды с `op_id`; повтор того же `op_id` не выполняется второй раз. Все деньги проходят через журнал `ledger`.

## Локальный запуск

```bash
npm ci
cp .dev.vars.example .dev.vars
npm run dev
```

Откройте http://127.0.0.1:8787 — при `DEV_AUTH=1` вход работает без Telegram.

```bash
npm test
```

## Деплой

Деплой идёт из GitHub Actions при пуше в `main`, если в репозитории заданы секреты:
`CLOUDFLARE_API_TOKEN`, `CLOUDFLARE_ACCOUNT_ID`, `BOT_TOKEN`, `WEBHOOK_SECRET`, `ADMIN_IDS`.
Перед миграциями база выгружается в артефакт сборки.

После первого деплоя один раз откройте `https://<адрес воркера>/tg/setup?key=<WEBHOOK_SECRET>` — подключится вебхук и кнопка «Играть».
Бот должен быть администратором канала `@autocrewgame`.

## Релиз

1. Добавить запись в начало `releases.json`.
2. Пуш в `main`: игроки увидят «Вышло обновление AUTO CREW».
3. В боте админ отправляет `/release_post`, проверяет предпросмотр и нажимает «Опубликовать». Ссылка на пост появится в окне «Что нового?».
