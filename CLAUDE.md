# AUTO CREW — правила проекта

- Список изменений (`releases.json`, окно «Что нового?», посты в канал) пишется только для игроков: что добавили, что убрали, какие баги в игре исправили. Про серверы, админку, деплой, базу и внутренние исправления не пишем.
- Новая запись в `releases.json` = баннер «Вышло обновление» у всех игроков. Для чисто технических изменений версию не поднимаем.
- Деньги и состояние считает только сервер (`src/worker/game.ts`); любые деньги — только через `money()`.
- Реплики с матом — в `src/shared/lines.ts`, всегда с мягким вариантом `{жёстко|мягко}`; мат лёгкий, бытовой, без оскорблений людей.
